# 🎮 컨트롤러 지원 요청

[English](CONTROLLER.en.md)

공식 지원하지 않는 컨트롤러도 **기타 컨트롤러 (수동 매핑)** 프로필로 쓸 수 있지만, 동작을 보장하지 않고 스크래치나 LR2 모드가 전용 프로필만큼 매끄럽지 않을 수 있습니다.
내 컨트롤러도 주작콘·FPS처럼 고르기만 하면 되는 **전용 프로필**이 있었으면 좋겠다면, 이 가이드대로 요청해 주세요.

지금 어떤 컨트롤러를 지원하는지는 [사용법과 설정 → 컨트롤러 지원 범위](USAGE.md#컨트롤러-지원-범위)를 보세요.

---

## 📋 준비물

- IIDXwidget 3.0.0 이상
- 요청할 컨트롤러 (PC에 연결된 상태)
- GitHub 계정 (요청을 올릴 때 필요합니다)

---

## 1️⃣ 신호 기록하기

1. 컨트롤러를 연결하고, 앱의 메뉴 → **컨트롤러 정보 수집**을 엽니다.
2. **장치**에서 컨트롤러를 고릅니다. 버튼을 눌렀을 때 **실시간 신호**가 바뀌면 제대로 고른 것입니다.
   - 바뀌지 않으면 다른 장치를 골라 보세요. 컨트롤러 하나가 여러 줄로 보이기도 합니다.
   - 목록에 아예 없으면 **다시 찾기**를 누르세요. 키보드 모드로 연결되는 컨트롤러는 목록에 나오지 않으니, 게임패드 모드로 바꿔 주세요.
3. 제품 이름, 지금 모드 이름, 증상 메모를 적습니다. 모르는 칸은 비워 두어도 됩니다.
4. 단계마다 **녹화** → 안내대로 동작 → **끝**을 누릅니다. 없는 버튼은 **건너뛰기**를 누르세요.

| 단계 | 할 일 |
|---|---|
| 아무것도 누르지 않기 | 3초 동안 손을 뗍니다. |
| 1~7번 건반 | 건반마다 천천히 3번 눌렀다 뗍니다. |
| 기타 버튼 | E1\~E4, START, SELECT 등을 하나씩 누릅니다. |
| 스크래치 | 시계·반시계 방향으로 천천히, 빠르게, 그리고 양방향 번갈아 돌립니다. |
| 건반 연타 | 1번 건반을 5초 동안 최대한 빠르게 연타합니다. |
| 동시 누르기 | 여러 건반을 동시에 몇 번 누릅니다. |
| 실제 플레이처럼 | 10초 정도 평소처럼 칩니다. |

> 💡 **모드가 여러 개인 컨트롤러**(LR2 모드 / 인피니타스 모드 등)는 모드를 바꾸고 **모드 이름**을 고친 뒤, **다른 모드로 처음부터**를 눌러 모드마다 한 번씩 기록해 주세요. 모드마다 신호가 다른 경우가 많습니다.

---

## 2️⃣ 결과 파일 저장하기

**결과 파일 저장**을 누르면 JSON 파일이 저장됩니다. 기본 위치는 다운로드 폴더입니다.

파일에 들어가는 것
- 컨트롤러의 제품 ID(VID:PID)와 이름, 단계별로 기록한 신호와 신호 간격
- 앱 버전, 버튼 레이아웃, 지금 쓰는 컨트롤러 프로필과 수동 매핑

파일에 들어가지 않는 것
- 키보드·마우스 입력 (목록에도 나오지 않습니다)
- 장치 경로 같은 PC 고유 정보, beatmania.app 계정 정보

기록은 이 PC에 파일로만 저장되고, 앱이 인터넷으로 보내지 않습니다.

---

## 3️⃣ GitHub에 요청 올리기

1. 수집 창의 **GitHub에 지원 요청 올리기**를 누르거나, [컨트롤러 지원 요청 양식](https://github.com/Coldlapse/IIDXwidget/issues/new?template=controller-support.yml)을 엽니다.
2. **컨트롤러 이름**, **지금 쓰는 IIDXwidget 프로필** 등 양식의 칸을 채웁니다.
3. 저장한 JSON 파일을 **수집 파일** 칸에 **끌어다 놓으면** 첨부됩니다. 칸을 누른 뒤 파일을 붙여 넣어도 됩니다.
   - 파일이 25MB를 넘으면 ZIP으로 압축해서 올려 주세요.
4. 양식 아래의 등록 버튼을 눌러 올립니다.

## 📬 그다음

- 기록을 보고 전용 프로필을 만들 수 있는지 확인합니다. 추가 기록이나 실물 확인을 부탁드릴 수 있습니다.
- 전용 프로필이 추가되면 업데이트로 나가고, 공식 지원 목록에 올라갑니다.
- 요청이 곧 공식 지원을 보장하지는 않습니다.

수동 매핑으로 써 보신 결과(잘 됨 / 일부만 됨 / 안 됨)만 알려주셔도 [확인된 컨트롤러](USAGE.md#컨트롤러-지원-범위) 목록에 반영합니다.
