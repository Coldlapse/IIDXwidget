# 🔍 채터링 감지

[English](CHATTER.en.md)

메뉴 → **채터링 감지**에서 보이는 숫자가 무엇을 뜻하는지, 어떻게 세는지, 설정의 두 가지 감지 방식이 어떻게 다른지 설명합니다.

---

## 채터링이 뭔가요?

건반 안의 스위치는 금속 접점이 붙었다 떨어지면서 신호를 만듭니다.
스위치가 낡거나 더러워지면 접점이 한 번에 딱 붙지 않고 **아주 짧게 여러 번 떨립니다.**
그러면 한 번 눌렀는데 컴퓨터는 **두 번 이상 눌린 것**으로 받아들일 수 있습니다. 이것을 **채터링**(이중 인식)이라고 합니다.

위쪽 선은 뗀 상태, 아래쪽 선은 누른 상태입니다.

**내가 한 것** (한 번 누름)
```
━━━━━┓                    ┏━━━━━
     ┗━━━━━━━━━━━━━━━━━━━━┛
```

**스위치 신호** (떨림 때문에 짧은 입력이 끼어듦)
```
━━━━━┓ ┏┓                 ┏━━━━━
     ┗━┛┗━━━━━━━━━━━━━━━━━┛
```

## IIDXwidget은 어떻게 세나요?

**뗀 뒤 같은 건반을 다시 누르기까지 걸린 시간**(간격)을 봅니다. [Rag](https://rag-oji.com/dakendisplay/) 님 위젯과 같은 방식입니다.

- 위 그림처럼 스위치가 떨리면 "뗐다가 아주 짧은 간격으로 다시 누른" 입력이 생깁니다.
- 사람이 같은 건반을 뗐다가 다시 누르려면 아무리 빨라도 수십 ms가 걸립니다. 그래서 간격이 아주 짧으면 떨림으로 봅니다.
- 건반마다 따로 셉니다.
- 창에서는 흰 건반(1·3·5·7번, 흰 글로우)과 검은 건반(2·4·6번, 파란 글로우)을 묶어서 보여주고, **묶음 평균의 2배 이상인 건반만 빨갛게** 강조합니다. 이유는 아래 [숫자는 이렇게 보세요](#-숫자는-이렇게-보세요)를 참고하세요.
- **이번 세션**(앱을 켠 뒤부터) 기준입니다. 채터링 감지 창을 닫아 두어도 계속 셉니다.
- 세션 기록 페이지의 **채터링** 숫자도 같은 기준입니다.

> ms(밀리초)는 1/1000초입니다. 30ms는 0.03초입니다.

## ⚙ 감지 설정 (두 가지 방식)

채터링 감지 창 오른쪽 위 **⚙ 설정**에서 바꿉니다. 메뉴 → **설정**의 "채터링 감지 설정 열기"로도 열 수 있습니다.

| 방식 | 채터링으로 세는 것 | 기본값 |
|---|---|---|
| **Rag** (기본) | 간격이 **감지 기준 미만**인 입력 전부 | 감지 기준 30ms |
| **Sadang** | 간격이 **하한 초과, 감지 기준 미만**인 입력만 | 하한 10ms, 감지 기준 30ms |

### Rag 방식: 스위치 상태를 빠짐없이 보기
- Rag 님 위젯과 같은 기준입니다. 기준(기본 30ms)보다 짧은 간격은 모두 셉니다.
- 스위치가 조금이라도 튀기 시작했는지 가장 먼저 알 수 있습니다.
- 대신 게임이 알아서 걸러 내는 아주 짧은 떨림까지 세기 때문에, 게임에서는 멀쩡한데 숫자가 올라갈 수 있습니다.

### Sadang 방식: 게임에서 문제가 될 만한 것만 보기
- 하한(기본 10ms) 이하의 아주 짧은 떨림은 **게임이 버리는 채터링**으로 보고 세지 않습니다.
- 하한과 기준 사이(기본 10ms 초과 30ms 미만)만 셉니다. 이 구간은 게임이 걸러 내지 못해 실제로 없는 입력이 될 수 있는 떨림입니다.
- 하한은 자주 하는 게임에 맞춰 조절하세요. 예를 들어 beatoraja와 LR2는 16ms 안의 변화를 걸러 내므로(아래 [게임별 입력 처리](#-게임별-입력-처리) 참고), 하한을 16ms로 두면 "그 게임에서도 걸리는 떨림"에 더 가깝게 볼 수 있습니다.

### 설정을 바꾸면
- **저장하는 즉시** 이번 세션의 기록 전체를 새 기준으로 다시 셉니다. 앱을 다시 켤 필요가 없습니다.
- 감지 기준과 하한은 1~100ms 사이 정수이고, Sadang 방식은 하한이 감지 기준보다 작아야 합니다.

## 숫자가 높으면 게임에서도 문제가 되나요?

**꼭 그렇지는 않습니다.** 이 숫자는 "게임에서 틀린 입력 수"가 아니라 **스위치가 얼마나 떨리는지**를 보여주는 지표입니다.

- IIDXwidget은 컨트롤러 신호를 1ms 단위로 모두 받기 때문에, 게임이 걸러 내는 짧은 떨림까지 볼 수 있습니다.
- 게임에서 실제로 문제가 되는지는 게임마다 다릅니다. 아래 [게임별 입력 처리](#-게임별-입력-처리)를 참고하세요.
- 채터링 숫자가 꾸준히 늘어난다면, 게임에서 이상한 입력이 느껴지기 전에 **스위치를 점검할 때가 됐다는 신호**로 보면 됩니다.

## 📈 숫자는 이렇게 보세요

채터링이 감지된다고 해서 반드시 그 버튼의 이중 인식이 심하다는 뜻은 아닙니다. **새로 산 스위치로 게임해도 대부분 채터링이 감지됩니다.**
중요한 것은 **실제로 게임에 영향을 주는 이중 인식**(예: 뒷푸어, 롱노트 콤보 끊김 등)이 있는지를 찾아내는 것입니다.

### 한 버튼만 유독 높다면
7개 버튼 중 특정 버튼만 수치가 크게 차이 난다면, 예를 들어 다른 버튼은 모두 20회 안팎인데 한 버튼만 70회 정도라면, 그 버튼의 스위치가 수명에 다다랐다는 것을 보여주는 하나의 근거가 될 수 있습니다.

### 2·4·6번은 조금 높게 나오기 쉽습니다
- 일반적으로 1P 기준 2번, 4번, 6번에는 엄중검 기준 왼손 중지, 오른손 검지, 오른손 중지가 놓입니다.
- 세 손가락은 공통적으로 타건할 때 힘이 강하고 제어가 편한 손가락입니다. 그래서 버튼을 더 세게 치게 될 수 있고, 이 때문에 채터링 수치가 비교적 높게 나오는 경향을 보였습니다.
- (개발자의 4년 플레이 경력을 바탕으로 한 개인적인 관찰이며, 근거가 명확하지는 않습니다.)
- 따라서 2·4·6번만 채터링 수치가 높은 것은 이상 증상으로 보기 어렵습니다. **1·3·5·7번과 2·4·6번을 따로 묶어서**, 각 묶음 안에서 비교해 보는 것을 권합니다. 채터링 감지 창도 이 기준으로 묶음 평균의 2배 이상인 건반만 강조합니다.

## 숫자가 계속 올라가요. 어떻게 하나요?

1. **어느 건반인지 확인하세요.** 같은 묶음(1·3·5·7번 또는 2·4·6번)의 다른 건반보다 유독 높다면 그 건반의 스위치 문제일 가능성이 큽니다.
2. **게임에서 실제로 이상한 입력이 있는지 확인하세요.** 뒷푸어나 롱노트 콤보 끊김이 없다면 급하게 손댈 필요는 없습니다.
3. **스위치를 점검하세요.** 접점 청소나 스위치 교체로 대부분 해결됩니다.
4. **컨트롤러 설정을 확인하세요.** 일부 컨트롤러와 자작 기판은 펌웨어에 떨림을 거르는 설정(디바운스)이 있습니다.
5. 같은 건반을 아주 빠르게 연타하는 곡(縦連)에서는 정상 입력이 기준에 걸릴 수도 있습니다. 스위치 상태를 볼 때는 그런 곡을 피해서 확인하세요.

## 🎮 게임별 입력 처리

같은 떨림이라도 게임마다 받아들이는 방식이 다릅니다. 소스가 공개된 **beatoraja**와 **LR2**(다시 작성된 소스인 OpenLR2 기준)를 살펴본 내용입니다.

### 먼저 알아둘 두 가지
- **확인 간격** : 게임이 건반 상태를 몇 ms마다 확인하는지. 이보다 짧게 끝나는 입력은 게임이 못 볼 수도 있습니다.
- **무시 시간** : 입력이 바뀐 뒤 몇 ms 동안 다음 변화를 무시하는지. 떨림을 거르는 장치입니다. 두 게임 모두 기본 **16ms**입니다 (프레임과는 관계없는 고정 시간).

| | LR2 | beatoraja |
|---|---|---|
| 확인 간격 | 화면 1프레임마다 (60fps면 약 16.7ms, fps에 따라 다름) | 1ms마다 (화면과 따로 확인) |
| 무시 시간 기준 | 마지막으로 **누른** 순간부터 16ms | 마지막으로 **바뀐** 순간부터 16ms (누름·뗌 모두) |
| 한 줄 요약 | "누르고 나서 16ms는 누른 걸로 친다" | "한 번 바뀌면 16ms는 더 안 바뀐다" |

### 경우별로 보면

| 상황 | LR2 | beatoraja |
|---|---|---|
| **누를 때 튐** (누르자마자 잠깐 떨어졌다 다시 붙음) | ✅ 걸러 냄 | ✅ 걸러 냄 |
| **뗄 때 튐** (떼자마자 잠깐 다시 붙음) | ❌ 없는 입력이 생길 수 있음. fps가 높을수록 잘 생김 | ✅ 걸러 냄 |
| 아주 짧게 톡 친 정상 입력 | ✅ 판정 정상 | ✅ 판정 정상 |
| 뗀 뒤 16ms 안에 다시 누름 | ✅ 바로 들어감 | ⚠️ 조금 늦게 들어가거나 사라짐 (사람에게는 거의 없는 경우) |
| 확인 간격보다 짧게 끝난 입력 | fps에 따라 가끔 못 봄 | 1ms 넘으면 봄 |

### 그래서
- **beatoraja**는 16ms 안의 떨림을 누르든 떼든 걸러 냅니다. 16ms보다 긴 간격의 떨림만 문제가 됩니다.
- **LR2**는 누를 때의 떨림은 거르지만 **뗄 때의 떨림은 거르지 못합니다.** 스위치가 뗄 때 튀면 LR2에서는 실제로 공POOR 같은 없는 입력이 될 수 있습니다.
- 이 차이 때문에 채터링 감지를 두 방식으로 나눴습니다. 스위치 자체를 보려면 **Rag**, 게임에서 문제가 될 떨림만 보려면 하한을 맞춘 **Sadang**을 쓰세요.
- IIDX(INFINITAS·아케이드)는 소스가 공개되어 있지 않아 확인하지 못했습니다.
