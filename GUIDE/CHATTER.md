# 🔍 채터링 감지

[English](CHATTER.en.md)

메뉴 → **채터링 감지**에서 보이는 숫자가 무엇을 뜻하는지, 어떻게 세는지 설명합니다.

---

## 채터링이 뭔가요?

건반 안의 스위치는 금속 접점이 붙었다 떨어지면서 신호를 만듭니다.
스위치가 낡거나 더러워지면 접점이 한 번에 딱 붙지 않고 **아주 짧게 여러 번 떨립니다.**
그러면 한 번 눌렀는데 컴퓨터는 **두 번 이상 눌린 것**으로 받아들일 수 있습니다. 이것을 **채터링**(이중 인식)이라고 합니다.

위쪽 선은 뗀 상태, 아래쪽 선은 누른 상태입니다.

**내가 한 것** (한 번 누름)
```
━━━━━┓                    ┏━━━━━
     ┗━━━━━━━━━━━━━━━━━━━━┛
```

**스위치 신호** (떨림 때문에 짧은 입력이 끼어듦)
```
━━━━━┓ ┏┓                 ┏━━━━━
     ┗━┛┗━━━━━━━━━━━━━━━━━┛
```

---

## IIDXwidget은 어떻게 세나요?

- **눌렀다가 15ms 이내에 떨어진 입력**을 채터링으로 셉니다.
- 사람이 건반을 정상적으로 치면 누르고 있는 시간이 보통 수십 ms 이상입니다. 15ms 이내로 떨어지는 입력은 거의 스위치 떨림입니다.
- 건반마다 따로 세고, 합계도 보여줍니다.
- **이번 세션**(앱을 켠 뒤부터) 기준입니다. 채터링 감지 창을 닫아 두어도 계속 셉니다.
- 세션 기록 페이지의 **채터링** 숫자도 같은 기준입니다.

> ms(밀리초)는 1/1000초입니다. 15ms는 0.015초입니다.

---

## 숫자가 높으면 게임에서도 문제가 되나요?

**꼭 그렇지는 않습니다.** 이 숫자는 "게임에서 틀린 입력 수"가 아니라 **스위치가 얼마나 떨리는지**를 보여주는 지표입니다.

- IIDXwidget은 컨트롤러 신호를 1ms 단위로 모두 받기 때문에, 게임이 걸러내는 짧은 떨림까지 셉니다.
- 게임도 떨림을 어느 정도 걸러냅니다. 방식은 게임마다 다릅니다.
  - **beatoraja** : 입력이 바뀐 뒤 16ms 동안 들어오는 변화는 무시합니다. 누를 때든 뗄 때든 떨림을 잘 걸러냅니다.
  - **LR2** : 누른 뒤 16ms 동안 떨어지는 것만 무시합니다. **뗄 때** 생기는 떨림은 걸러내지 못해서, 없는 입력(공POOR 등)이 생길 수 있습니다.
- 그래서 채터링 숫자가 꾸준히 늘어난다면, 게임에서 이상한 입력이 느껴지기 전에 **스위치를 점검할 때가 됐다는 신호**로 보면 됩니다.

---

## 숫자가 계속 올라가요. 어떻게 하나요?

1. **어느 건반인지 확인하세요.** 특정 건반만 높다면 그 건반의 스위치 문제일 가능성이 큽니다.
2. **스위치를 점검하세요.** 접점 청소나 스위치 교체로 대부분 해결됩니다.
3. **컨트롤러 설정을 확인하세요.** 일부 컨트롤러와 자작 기판은 펌웨어에 떨림을 거르는 설정(디바운스)이 있습니다.
4. 가끔 1~2회 올라가는 정도는 걱정하지 않아도 됩니다.
