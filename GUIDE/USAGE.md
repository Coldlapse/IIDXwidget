# 📘 사용법과 설정

[English](USAGE.en.md)

IIDXwidget의 화면 구성, 메뉴, 설정 항목이 각각 무엇을 뜻하는지 정리한 가이드입니다.
OBS에 처음 연결하는 중이라면 [연결 가이드](CONNECTION.md)부터 보세요.

---

## 🖥 화면 구성

앱 창과 OBS 위젯은 **항상 같은 화면, 같은 숫자**를 보여줍니다. 앱 창에서 보이는 그대로 방송에 나간다고 생각하면 됩니다.

- **스크래치** : 턴테이블을 돌리는 방향에 따라 원판이 돌아갑니다. 커스텀 이미지를 넣을 수 있습니다.
- **건반** : 누르는 동안 색이 바뀝니다. 롱노트(CN)로 오래 누르고 있으면 롱노트 색으로 한 번 더 바뀝니다. 건반 위 숫자는 그 건반의 평균 릴리즈(ms)입니다.
- **세션 정보**
  - **Session** : 이번 세션에서 누른 횟수 (타건 수)
  - **Uptime** : 앱을 켠 뒤 지난 시간
  - **Release** : 전체 건반의 평균 릴리즈(ms). 롱노트로 누른 입력은 빼고 계산합니다 ([Rag](https://rag-oji.com/dakendisplay/) 님 위젯과 같은 방식)
  - **KPS** : 최근 1초 동안 누른 횟수

> 📌 **세션**이란 앱을 켠 순간부터 끌 때까지를 말합니다. 모든 숫자는 앱을 켤 때 0부터 시작하고, 앱을 끄면 사라집니다.

릴리즈가 무엇인지는 [RELEASE 가이드](RELEASE.md)를 참고하세요.

## 📋 메뉴

- **메뉴**
  - **설정** : 아래 [설정 항목](#-설정-항목)을 바꿉니다.
  - **로그** : 컨트롤러 인식 여부나 오류 메시지를 확인합니다. 문제가 생기면 여기부터 보세요.
  - **세션 기록** : 이번 세션의 타건 수, 전송한 양, 남은 양을 보고 [beatmania.app](https://beatmania.app)으로 타건 기록을 보냅니다.
  - **채터링 감지** : 건반별 채터링(이중 인식) 횟수를 봅니다. 창 오른쪽 위 **⚙ 설정**에서 감지 방식(Rag / Sadang)과 기준을 바꿀 수 있습니다. 자세한 내용은 [채터링 감지 가이드](CHATTER.md)를 참고하세요.
  - **정보 / 기여자** : 앱 버전과 만든 사람들
  - **업데이트 확인** : 새 버전이 있는지 바로 확인합니다. 앱을 켤 때도 자동으로 확인합니다.
  - **재시작** : 서버와 컨트롤러 연결을 다시 엽니다. 세션 숫자는 그대로 이어집니다.
  - **끝내기** : 앱을 끕니다.
- **Language** : 한국어 / English
- **가이드** : 이 문서를 포함한 모든 가이드와 [3.0.0 업데이트 안내](WHATSNEW.md)를 앱 안에서 볼 수 있습니다.

## 🔧 설정 항목

설정을 바꾼 뒤 **저장**을 눌러야 적용됩니다. 저장하면 OBS 위젯에도 바로 반영됩니다.

### 앱 기본 설정

| 항목 | 설명 |
|---|---|
| **Windows 시작 시 자동 실행** | 컴퓨터를 켜면 IIDXwidget이 자동으로 실행됩니다. |
| **위젯 홍보 박스 표시** | 위젯 아래(또는 위)에 IIDXwidget 저장소 주소를 작게 띄웁니다. 켜주시면 감사하겠습니다 🙏 |
| **컨트롤러 프로필** | 사용하는 컨트롤러를 고릅니다. 아래 [컨트롤러 프로필](#컨트롤러-프로필)을 참고하세요. |
| **LR2 모드 감지 (주작콘 전용)** | 주작콘을 LR2에서 쓰면 턴테이블 신호가 다르게 들어옵니다. 켜두면 LR2 모드를 알아서 감지해서 스크래치를 제대로 표시합니다. |

### 컨트롤러 프로필

- **PHOENIXWAN+ (주작콘) / FPS EMP Gen2** : 고르기만 하면 바로 인식됩니다.
- **그 외 컨트롤러** : 그 밖의 컨트롤러나 아두이노 같은 자작 기판용입니다. 주작콘·FPS가 연결되어 있으면 매핑 없이 바로 인식하고, 그 밖의 기판은 직접 매핑합니다.
  - 매핑 표에서 칸을 클릭한 뒤 컨트롤러 버튼을 누르면 매핑됩니다. 칸을 비우면 해제됩니다.
  - 턴테이블이 **버튼**으로 동작하는 기판이라면 '턴테이블 시계 방향 / 반시계 방향' 칸에 매핑합니다.
  - 턴테이블이 **축**으로 동작하는 기판이라면 '턴테이블 (축)'의 **학습**을 누르고 2초 동안 턴테이블을 돌리세요.
- **키보드** (BM으로 하라고 만든 게임을 꾸역꾸역 키보드로 하는 멍청이) : 키보드 매핑 표에서 칸을 클릭한 뒤 쓰고 싶은 키를 누릅니다.

### beatmania.app 타건 기록

| 항목 | 설명 |
|---|---|
| **beatmania.app 계정** | [beatmania.app](https://beatmania.app) 마이페이지 → **API 토큰 발급**에서 받은 토큰을 붙여 넣고 **연결**을 누릅니다. 서버에 확인한 뒤 바로 저장되고, 연결된 계정 이름이 표시됩니다. 토큰은 이 PC의 Windows 계정으로 암호화해서 저장합니다. |
| **종료할 때 남은 타건 기록 자동 전송** | 앱을 끌 때 이번 세션에서 아직 보내지 않은 양을 자동으로 보냅니다. 기본값은 꺼짐입니다. 꺼져 있으면 보내지 않은 양은 앱을 끌 때 사라집니다. |

- 직접 보내려면 메뉴 → **세션 기록** → **지금 전송**을 누릅니다. 아직 보내지 않은 양만 보내므로 여러 번 눌러도 중복되지 않습니다.
- 날짜별 기록은 beatmania.app 마이페이지에서 볼 수 있습니다. 서버는 전송을 받은 시각(한국 시간) 기준으로 날짜를 나눕니다.

### 연결

| 항목 | 설명 |
|---|---|
| **서버 포트** | OBS 브라우저 소스 주소에 들어가는 번호입니다. 기본값 8080. 바꾸면 OBS 주소도 같이 바꿔야 합니다. |
| **웹소켓 포트** | 위젯이 실시간 입력을 받는 번호입니다. 기본값 5678. 위젯이 알아서 연결하므로 OBS에 따로 입력하지 않습니다. |

다른 프로그램이 같은 포트를 쓰고 있을 때만 바꾸면 됩니다. 포트가 무엇인지는 [연결 가이드](CONNECTION.md)에 설명되어 있습니다.

### 위젯 표시

| 항목 | 설명 |
|---|---|
| **세션 정보 표시 위치** | 세션 정보를 위젯 위 / 아래에 두거나 숨깁니다. |
| **버튼 레이아웃** | 1P(스크래치 왼쪽) / 2P(스크래치 오른쪽) |

### 릴리즈·채터링

릴리즈 계산 기준은 [Rag](https://rag-oji.com/dakendisplay/) 님 위젯과 같게 맞춰져 있습니다. 자세한 계산 방식은 [RELEASE 가이드](RELEASE.md)를 보세요.

| 항목 | 설명 |
|---|---|
| **전체 Release 수집 표본 갯수** | 전체 평균 릴리즈를 최근 몇 번의 입력으로 계산할지 정합니다. 기본값 2000 (Rag 님 위젯과 같음). 높을수록 숫자가 천천히 변합니다. |
| **버튼별 Release 수집 표본 갯수** | 건반 위 릴리즈 숫자를 건반마다 최근 몇 번의 입력으로 계산할지 정합니다. 기본값 300 (Rag 님 위젯과 같음). |
| **롱노트(CN) 판정 시간** | 이 시간 이상 누른 입력은 롱노트로 보고 릴리즈 평균에서 뺍니다. 누르고 있는 동안 건반이 롱노트 색으로 바뀝니다. 기본값 200ms, 100~500ms. |
| **채터링 감지 설정 열기** | 채터링 감지 창의 설정 화면을 엽니다. 감지 방식과 기준은 [채터링 감지 가이드](CHATTER.md)를 보세요. |

표본 갯수와 롱노트 판정 시간을 바꾸면 저장하는 즉시 이번 세션 기록을 새 기준으로 다시 계산합니다.

### 위젯 외관

| 항목 | 설명 |
|---|---|
| **위젯 컨테이너 배경 투명하게** | 위젯 뒤 배경을 투명하게 해서 방송 화면 위에 위젯만 보이게 합니다. |
| **키 위에 release 수치 표시** | 건반 위 릴리즈 숫자를 보이거나 숨깁니다. 기본값은 표시. |
| **스크래치 이미지 모드** | **1장** : 이미지 하나가 회전 방향에 따라 돌아갑니다. **2장** : 회전 방향마다 다른 이미지를 보여줍니다. |
| **스크래치 커스텀 이미지** | 원판에 쓸 이미지를 고릅니다. **삭제**를 누르면 기본 원판으로 돌아갑니다. |
| **색상** | 위젯 배경, 스크래치 배경, 입력 전/입력 중 색, 글자색, 롱노트로 누르고 있는 건반 색을 바꿉니다. |

## 💡 알아두면 좋은 것

- 앱을 껐다 켜도 OBS 위젯은 알아서 다시 연결됩니다. 앱이 꺼져 있는 동안에는 OBS 화면에 "위젯 프로그램과 연결이 끊겼습니다"가 뜹니다.
- 앱을 업데이트한 직후에는 OBS 브라우저 소스 속성에서 **현재 페이지의 캐시를 새로고침**을 한 번 눌러주세요.
- 궁금한 점이나 버그는 [Issues](https://github.com/Coldlapse/IIDXwidget/issues)로 알려주세요.
