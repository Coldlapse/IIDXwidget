# 📘 사용법과 설정

[English](USAGE.en.md)

IIDXwidget의 화면 구성, 메뉴, 설정 항목이 각각 무엇을 뜻하는지 정리한 가이드입니다.
OBS에 처음 연결하는 중이라면 [연결 가이드](CONNECTION.md)부터 보세요.

## 🖥 화면 구성

앱 창과 OBS 위젯은 **항상 같은 화면, 같은 숫자**를 보여줍니다. 앱 창에서 보이는 그대로 방송에 나간다고 생각하면 됩니다.

- **스크래치** : 턴테이블을 돌리는 방향에 따라 원판이 돌아갑니다. 커스텀 이미지를 넣을 수 있습니다.
- **건반** : 누르는 동안 색이 바뀝니다. 롱노트(CN)로 오래 누르고 있으면 롱노트 색으로 한 번 더 바뀝니다. 건반 위 숫자는 그 건반의 평균 릴리즈(ms)입니다.
- **세션 정보 (계기판)** : 위젯 본체 아래(또는 위)에 붙어 있는 패널입니다. 키보드 프로필이면 건반 위에 **INPUT · KB** 표시가 작게 나옵니다.
  - **Session** : 이번 세션에서 누른 횟수 (타건 수)
  - **Uptime** : 앱을 켠 뒤 지난 시간
  - **Release** : 전체 건반의 평균 릴리즈(ms). 롱노트로 누른 입력은 빼고 계산합니다 ([Rag](https://rag-oji.com/dakendisplay/) 님 위젯과 같은 방식)
  - **KPS** : 최근 1초 동안 누른 횟수. 기본으로 **스피드미터 게이지**로 보입니다. 게이지의 70%까지가 보통 영역, 나머지 30%가 빨간 영역이고, 빨간 영역에 들어가면 색이 주황에서 빨강으로 달아오르며 빛이 번집니다. 게이지 끝에 닿으면 게이지 끝과 숫자가 살짝 떨리며(레드라인), 끝을 넘어도 게이지는 끝에서 멈추고 숫자는 실제 값을 그대로 보여줍니다.

> 📌 **세션**이란 앱을 켠 순간부터 끌 때까지를 말합니다. 모든 숫자는 앱을 켤 때 0부터 시작하고, 앱을 끄면 사라집니다.

릴리즈가 무엇인지는 [RELEASE 가이드](RELEASE.md)를 참고하세요.

## 📋 메뉴

- **메뉴**
  - **설정** : 아래 [설정 항목](#-설정-항목)을 바꿉니다.
  - **로그** : 컨트롤러 인식 여부나 오류 메시지를 확인합니다. 문제가 생기면 여기부터 보세요.
  - **세션 기록** : 이번 세션의 타건 수, 전송한 양, 남은 양을 보고 [beatmania.app](https://beatmania.app)으로 타건 기록을 보냅니다.
  - **컨트롤러 정보 수집** : 공식 지원하지 않는 컨트롤러의 신호를 기록해 공식 지원을 요청할 때 씁니다. [컨트롤러 지원 요청 가이드](CONTROLLER.md)를 참고하세요.
  - **채터링 감지** : 건반별 채터링(이중 인식) 횟수를 봅니다. 1·3·5·7번과 2·4·6번을 묶어서 보여주고, 묶음 안에서 유독 튀는 건반을 빨갛게 강조합니다. 창 오른쪽 위 **⚙ 설정**에서 감지 방식(Rag / Coldlapse)과 기준을 바꿀 수 있습니다. 자세한 내용은 [채터링 감지 가이드](CHATTER.md)를 참고하세요.
  - **개발자 정보/기여자** : 앱 버전, 개발자 소개와 링크, 후원(Buy me a coffee), 기여자 목록을 한 창에서 봅니다.
  - **업데이트 확인** : 새 버전이 있는지 바로 확인합니다. 앱을 켤 때도 자동으로 확인합니다.
  - **재시작** : 서버와 컨트롤러 연결을 다시 엽니다. 세션 숫자는 그대로 이어집니다.
  - **끝내기** : 앱을 끕니다.
- **Language** : 한국어 / English
- **가이드** : 이 문서를 포함한 모든 가이드와 [3.0.0 업데이트 안내](WHATSNEW.md)를 앱 안에서 볼 수 있습니다.

## 🔧 설정 항목

설정을 바꾼 뒤 **저장**을 눌러야 적용됩니다. 저장하면 OBS 위젯에도 바로 반영됩니다.

### 앱 기본 설정

| 항목 | 설명 |
|---|---|
| **Windows 시작 시 자동 실행** | 컴퓨터를 켜면 IIDXwidget이 자동으로 실행됩니다. |

### 컨트롤러: 버튼 레이아웃과 DP

| 항목 | 설명 |
|---|---|
| **버튼 레이아웃** | **1P**(스크래치 왼쪽) / **2P**(스크래치 오른쪽) / **DP**(1P + 2P) |

- **DP**를 고르면 **2P 컨트롤러** 구역이 나타나서, 1P와 2P에 컨트롤러를 각각 정할 수 있습니다. 두 쪽의 프로필이 달라도 되고(예: 1P 주작콘 + 2P FPS), 한쪽을 키보드로 써도 됩니다.
- 위젯은 1P 본체와 2P 본체가 가운데 여백(40px, 위젯 배경색)으로 이어진 모양으로 나오고, 세션 정보 계기판은 가운데에 사다리꼴로 붙습니다. 키보드를 쓰는 쪽이 있으면 두 본체 사이 위쪽에 **1P · KB**, **2P · KB**(둘 다면 **INPUT · KB**)가 표시됩니다. 타건 수·KPS·평균 릴리즈는 1P·2P를 합친 값입니다.
- DP 위젯은 가로 1000px이라, OBS 브라우저 소스를 **1320×600**으로 잡아 주세요. 앱 창도 DP일 때만 가로가 넓어집니다.
- 채터링 감지 창에는 2P 건반이 1P 아래에 하나 더 나오고, 1P·2P를 따로 비교합니다.

### 컨트롤러 프로필

사이드마다(SP는 하나, DP는 1P·2P) 프로필과 **장치**를 고릅니다. 키보드·기타 컨트롤러 매핑 표는 프로필 바로 아래에 나옵니다.

- **장치** : 연결된 컨트롤러 중 그 프로필에 맞는 것만 목록에 나옵니다. 하나뿐이면 하나만 보입니다. 같은 컨트롤러가 여러 대면(1P·2P 기판 두 대 등) 이름 앞에 `[S/N …1234]`처럼 시리얼 번호 끝 4자리가, 시리얼이 없는 기기는 `[#1]`, `[#2]`가 붙습니다. 목록은 **다시 찾기**를 누르면 새로 고쳐집니다. 다른 USB 포트에 꽂아도 시리얼로 같은 장치를 찾고, 저장한 장치가 빠져 있으면 연결된 다른 장치를 씁니다.
- DP에서 1P와 2P에 같은 장치를 고를 수는 없습니다.
- 컨트롤러를 뺐다 다시 꽂거나 앱을 켠 뒤에 꽂아도, 2초쯤 안에 저장이나 재시작 없이 입력이 다시 들어옵니다.
- **LR2 모드 감지 (주작콘 전용)** : 주작콘·FPS·LMT Classic 프로필에서만 보입니다. 주작콘을 LR2에서 쓰면 턴테이블 신호가 다르게 들어오는데, 켜두면 LR2 모드를 알아서 감지해서 스크래치를 제대로 표시합니다. LR2 모드를 쓸 일이 없다면 꺼도 됩니다.
- **턴테이블 방향 반전** : 키보드를 뺀 모든 프로필에 있습니다. 옆의 작은 원판이 지금 들어오는 턴테이블 입력대로 OBS 위젯과 같은 방향으로 돕니다. 턴테이블을 시계 방향으로 돌렸는데 원판이 반대로 돌면 켜세요. 체크를 바꾸거나 프로필·장치를 바꾸면 저장하기 전에 원판에서 바로 확인할 수 있고, 저장하면 여기서 보이는 회전 방향이 위젯에 반영됩니다. (기타 컨트롤러는 아날로그 턴테이블에서 축을 학습한 뒤에 원판이 움직입니다)

- **PHOENIXWAN+ (주작콘) / FPS EMP Gen2** : 고르기만 하면 바로 인식됩니다.
- **PHOENIXWAN+ LMT Classic** : 피닉스완 LMT Classic 기판은 이 프로필을 고르세요. 전용 프로그램(IIDXOLLER)에서 고른 모드에 따라 USB로 보이는 모양이 다른데, 아래 세 모드는 모두 이 프로필로 동작합니다.
  - **PS2 및 BLE 모드**, **EAC2dx 및 HID 모드** : 고르기만 하면 됩니다. 턴테이블 방향은 IIDXOLLER의 턴테이블 **반전**이 꺼진 상태(기본) 기준입니다. IIDXOLLER에서 반전을 켜 두셨다면 앱에서도 **턴테이블 방향 반전**을 켜세요.
  - **LR2 레이아웃 모드** : 주작콘처럼 **LR2 모드 감지**를 켜면 됩니다.
  - 그 밖의 모드(beatoraja 레이아웃, 키보드 및 마우스, DS4, NS)는 지원하지 않습니다. **기타 컨트롤러 (수동 매핑)** 이나 **키보드** 프로필로 매핑해 쓰세요.
- **RED-LMS** : 1P와 2P가 따로 연결되는 더블콘입니다. 장치 목록에 `RED-LMS 1P`, `RED-LMS 2P`가 따로 나오니, 사이드마다 맞는 쪽을 고르세요. 턴테이블 방향은 IIDXOLLER의 턴테이블 **반전**이 꺼진 상태 기준입니다. 반전을 켜 둔 쪽(예: INFINITAS 선곡 방향 때문에 1P만 반전)은 앱에서도 그 사이드의 **턴테이블 방향 반전**을 켜세요.
- **arcin-infinitas** : [arcin-infinitas](https://github.com/kinetic-flow/arcin-infinitas) — kinetic-flow님이 개발하신 arcin 기판의 INFINITAS용 펌웨어에 한하여 작동을 보장합니다. 설정 도구에서 기판 이름(라벨)을 바꿔도 인식됩니다. 턴테이블 모드는 모두 알아서 따라갑니다.
  - **아날로그** (INFINITAS·beatoraja 권장) : 턴테이블 위치를 그대로 읽습니다.
  - **디지털** (LR2 권장) : 턴테이블이 돌아가는 방향만 들어오므로, 주작콘 LR2 모드처럼 방향이 바뀔 때마다 원판을 조금씩 돌립니다. 켤 옵션은 따로 없습니다.
  - **디지털 + 아날로그** : 아날로그 위치를 읽습니다.
  - arcin 설정 도구에서 턴테이블 방향을 뒤집었다면(아날로그 반전 등) 위의 **턴테이블 방향 반전**으로 위젯 방향을 맞추세요.
  - arcin을 **키보드 모드**로 쓰면 **키보드** 프로필로 매핑해 주세요.
- **기타 컨트롤러 (수동 매핑)** : 공식 지원하지 않는 컨트롤러나 아두이노 같은 자작 기판용입니다. 버튼을 하나씩 직접 매핑합니다. 공식 지원 컨트롤러(주작콘·FPS·arcin-infinitas 등)도 이 프로필에서 직접 매핑해 쓸 수 있지만, 보통은 전용 프로필이 더 편합니다.
  - 매핑 표에서 칸을 클릭한 뒤 컨트롤러 버튼을 누르면 매핑됩니다. 칸을 비우면 해제됩니다.
  - 턴테이블은 **버튼 턴테이블 / 아날로그 턴테이블** 스위치로 둘 중 하나를 고릅니다. 고르지 않은 쪽의 매핑·학습 값도 지워지지 않고 남아 있어서, 다시 바꾸면 그대로 쓸 수 있습니다. 3.0.1 이하에서 축을 학습해 두셨다면 아날로그 턴테이블로, 아니면 버튼 턴테이블로 시작합니다.
  - **버튼 턴테이블** : 턴테이블이 버튼으로 동작하는 기판(주작콘 LR2 모드 등)이라면 '턴테이블 시계 방향 (↓) / 반시계 방향 (↑)' 칸에 매핑합니다. 주작콘 LR2 모드처럼 누를 때 원판이 5칸 돌고, 떼면 스크래치 불이 꺼집니다. 반대로 돌면 두 칸의 번호를 서로 바꾸세요. 3.0.1까지 잘 되다가 3.0.2부터 턴테이블이 이상하다면 **Legacy Button Turntable**을 켜세요 (누를 때 2칸, 떼도 불이 켜진 채인 예전 방식). 매핑할 때 들어온 신호가 아날로그(축)로 보이면 아날로그 턴테이블 모드를 권하는 안내가 뜹니다 (매핑은 그대로 됩니다).
  - **아날로그 턴테이블** : 턴테이블이 축으로 동작하는 기판이라면 **학습**을 누르고 2초 동안 턴테이블을 돌리세요. 학습이 끝나면 옆의 원판이 턴테이블을 따라 돕니다. 시계 방향으로 돌렸을 때 원판이 반대로 돌면 **턴테이블 방향 반전**을 켜세요. **할당 해제**를 누르면 학습한 축을 지웁니다.
- **키보드** (BM으로 하라고 만든 게임을 꾸역꾸역 키보드로 하는 멍청이) : 키보드 매핑 표에서 칸을 클릭한 뒤 쓰고 싶은 키를 누릅니다.

### 컨트롤러 지원 범위

| 구분 | 대상 | 설명 |
|---|---|---|
| ✅ **공식 지원** | PHOENIXWAN+ (주작콘), PHOENIXWAN+ LMT Classic 기판, RED-LMS, FPS EMP 2세대, arcin-infinitas | 전용 프로필이 있어 고르기만 하면 바로 동작합니다. |
| ✅ **공식 지원** | 키보드 | 키보드 프로필에서 키를 매핑해 씁니다. |
| 🔧 **수동 매핑** (동작할 수 있음) | 그 밖의 IIDX 컨트롤러, 자작 기판 | **기타 컨트롤러 (수동 매핑)** 프로필에서 버튼을 직접 매핑합니다. **동작을 보장하지 않습니다.** |

시중의 모든 컨트롤러를 지원하는 것은 아닙니다. 기타 컨트롤러 프로필은 아케이드식 IIDX 컨트롤러와 자작 기판에 맞춰 만들었고, 아직 실제 기기로 확인한 컨트롤러는 없습니다.

**동작할 가능성이 높은 경우**
- 게임패드(HID) 모드로 연결되는 아케이드식 IIDX 컨트롤러
- 아두이노 등으로 만든 자작 기판
- PS2용 컨트롤러를 USB 변환기로 연결한 경우

**안 되거나 확인이 필요한 경우**
- **Xbox(XInput) 모드**로 연결되는 컨트롤러 : 앱이 장치를 찾지 못할 수 있습니다. 컨트롤러에서 모드를 바꿀 수 있다면 게임패드(HID) 모드로 바꿔 보세요.
- **키보드 모드**로 연결되는 컨트롤러 : 기타 컨트롤러가 아니라 **키보드** 프로필을 쓰세요.
- 버튼이 아주 많거나 아날로그 스틱이 있는 **일반 게임패드** : 매핑할 때 엉뚱한 번호가 잡히거나 일부 버튼을 읽지 못할 수 있습니다.
- 게임패드가 **여러 개** 연결된 경우 : 목록에 모두 나오므로 **장치**에서 쓸 컨트롤러를 골라 주세요. 이름이 같으면 시리얼 번호 끝 4자리(없으면 #1, #2)로 구분되니, 헷갈리면 쓰지 않는 게임패드를 빼 두세요.
- 코나미 공식 INFINITAS 컨트롤러 : 아직 확인하지 못했습니다.

**내 컨트롤러가 되는지 확인하는 법**
1. 컨트롤러 프로필을 '기타 컨트롤러 (수동 매핑)'으로 바꿉니다.
2. 매핑 표 칸을 누르고 컨트롤러 버튼을 눌러, 번호가 들어오는지 봅니다.
3. 건반 7개와 턴테이블이 모두 잡히면 **저장**을 누르고 위젯에서 반응을 확인합니다.

**확인된 컨트롤러** : 아직 없습니다. 기타 컨트롤러로 써 보셨다면 컨트롤러 이름과 결과(잘 됨 / 일부만 됨 / 안 됨)를 [Issues](https://github.com/Coldlapse/IIDXwidget/issues)에 알려주세요. 이 목록에 반영하겠습니다.

표본 갯수와 롱노트 판정 시간을 바꾸면 저장하는 즉시 이번 세션 기록을 새 기준으로 다시 계산합니다.

## 🐧 리눅스 (실험적 지원)

리눅스용 AppImage를 함께 배포합니다. 앱 화면과 OBS 위젯은 확인했지만, 컨트롤러 입력은 아직 리눅스 실제 기기로 확인하지 못해 **실험적 지원**입니다. 써 보신 결과를 [Issues](https://github.com/Coldlapse/IIDXwidget/issues)로 알려주세요.

1. [Releases](https://github.com/Coldlapse/IIDXwidget/releases/latest)에서 `IIDXwidget-x.x.x-x86_64.AppImage`와 `70-iidxwidget.rules`를 받습니다.
2. AppImage에 실행 권한을 줍니다. 파일 속성에서 "실행 허용"을 켜거나 터미널에서 `chmod +x IIDXwidget-*.AppImage`
3. 실행합니다. FUSE 2가 없다는 오류가 나면 설치해 주세요.
   - 아치 계열(CachyOS 등): `sudo pacman -S fuse2`
   - 우분투·데비안 계열: `sudo apt install libfuse2`
4. **컨트롤러 권한 (처음 한 번):** 리눅스는 일반 사용자가 컨트롤러 장치를 바로 읽지 못합니다. 받은 규칙 파일을 넣고 컨트롤러를 뺐다 다시 꽂아 주세요.
   ```
   sudo cp 70-iidxwidget.rules /etc/udev/rules.d/
   sudo udevadm control --reload && sudo udevadm trigger
   ```
   - 공식 지원 컨트롤러는 이 파일만으로 됩니다. 기타 컨트롤러(수동 매핑)는 파일 안의 예시처럼 그 기기의 VID:PID 한 줄을 추가하세요. VID:PID는 메뉴 → **컨트롤러 정보 수집**이나 `lsusb`로 확인할 수 있습니다.
   - 장치 목록에는 보이는데 입력이 안 들어오면 대부분 이 단계가 빠진 경우입니다. 메뉴 → **로그**에도 안내가 나옵니다.

알아둘 점
- **키보드 모드**는 X11 세션에서 동작합니다. KDE Plasma·GNOME의 기본인 Wayland 세션에서는 X11 창(XWayland로 띄운 LR2oraja 등)에 포커스가 있을 때만 키보드 입력을 읽습니다.
- **자동 업데이트**를 지원합니다. AppImage 파일이 있는 폴더에 쓰기 권한이 있어야 합니다(홈 폴더 권장).
- **로그인할 때 자동 실행**을 켜면 `~/.config/autostart`에 실행 파일이 등록됩니다. AppImage를 다른 곳으로 옮겼다면 설정을 한 번 껐다 켜 주세요.
- beatmania.app 토큰은 KWallet이나 GNOME 키링으로 암호화해서 저장합니다. 키링이 없으면 약한 방식으로 저장됩니다.
- 앱이 켜지지 않으면 터미널에서 실행해 오류를 확인해 주세요. 일부 배포판(우분투 24.04 이상 등)에서는 `--no-sandbox` 옵션을 붙여야 켜질 수 있습니다.
- 투컴 방송에서 방화벽(ufw)을 쓴다면 포트를 열어 주세요: `sudo ufw allow 8080,5678/tcp`
- 설정 파일은 `~/.config/iidxwidget/`에 있습니다.

## 💡 알아두면 좋은 것

- 앱을 껐다 켜도 OBS 위젯은 알아서 다시 연결됩니다. 앱이 꺼져 있는 동안에는 OBS 화면에 "위젯 프로그램과 연결이 끊겼습니다"가 뜹니다.
- 앱은 하나만 실행됩니다. 이미 켜져 있을 때 다시 실행하면 켜져 있던 창이 앞으로 나옵니다.
- 앱을 업데이트한 직후에는 OBS 브라우저 소스 속성에서 **현재 페이지의 캐시를 새로고침**을 한 번 눌러주세요.
- 궁금한 점이나 버그는 [Issues](https://github.com/Coldlapse/IIDXwidget/issues)로 알려주세요.
