# 🎉 3.0.0 업데이트 안내

[English](WHATSNEW.en.md)

2.x에서 3.0.0으로 업데이트하신 분을 위한 안내입니다. 바뀐 점과 새 기능을 정리했습니다.

---

## ⚠️ 먼저 해 주세요: OBS 위젯 새로고침

3.0.0에서는 OBS에 띄우는 위젯 화면도 새로 바뀌었습니다. OBS가 예전 화면을 기억하고 있어서, **한 번은 직접 새로고침**해야 새 위젯이 나옵니다.

1. OBS에서 IIDXwidget **브라우저 소스**를 더블클릭해 속성을 엽니다.
2. 아래쪽의 **현재 페이지의 캐시를 새로고침**을 누릅니다.
3. **확인**을 누릅니다.

버튼을 찾기 어렵다면 **OBS를 껐다 켜도** 됩니다.
이번 한 번만 하면 됩니다. 앞으로는 설정을 바꾸거나 앱을 다시 켜도 위젯이 알아서 따라옵니다.

---

## 📊 숫자가 달라 보일 수 있어요

### 릴리즈 계산이 Rag 님 위젯과 같아졌습니다
- **롱노트(CN)로 누른 입력은 평균에서 뺍니다.** 예전에는 롱노트도 99ms로 평균에 들어가서 숫자가 높게 나왔습니다. 그래서 3.0.0에서는 평균 릴리즈가 **예전보다 낮게** 보일 수 있습니다.
- 표본 갯수 기본값이 **전체 2000개, 건반별 300개**로 바뀌었습니다. 예전 기본값(200)을 그대로 쓰셨다면 자동으로 새 기본값으로 바뀌었고, 직접 바꾼 값은 그대로입니다.
- 롱노트로 누르고 있는 건반은 **다른 색**으로 보입니다. 색은 설정에서 바꿀 수 있습니다.
- 자세한 내용: [RELEASE 가이드](RELEASE.md)

### 채터링 감지 방식이 바뀌었습니다
- 예전: 누르고 있던 시간이 15ms 이하면 채터링
- 지금: **뗀 뒤 같은 건반을 다시 누르기까지 간격**으로 판단 (Rag 님 위젯과 같은 방식)
- 채터링 감지 창의 **⚙ 설정**에서 두 가지 방식(Rag / Sadang)과 기준을 고를 수 있습니다.
- 자세한 내용: [채터링 감지 가이드](CHATTER.md)

### 모든 숫자가 "세션" 단위입니다
- 타건 수, 업타임, 릴리즈, 채터링 모두 **앱을 켤 때 0부터** 시작해서 끌 때까지 셉니다.
- 앱 창과 OBS 위젯은 이제 **항상 같은 숫자**를 보여줍니다.

## ✨ 새 기능

- **백신 오탐 해결** : 2.1.0 이하에서 Windows Defender가 바이러스로 막던 문제를 없앴습니다. 키보드 입력을 읽는 부품을 바꿨습니다.
- **한국어 / English** : 메뉴 → Language
- **기타 컨트롤러 (수동 매핑)** : 공식 지원하지 않는 컨트롤러나 자작 기판도 버튼을 눌러 직접 매핑할 수 있습니다. 턴테이블이 축으로 동작하는 기판은 "학습"으로 찾습니다.
- **위젯 디자인 개편** : 따로 떠 있던 세션 정보 상자가 위젯 본체에 붙은 계기판으로 바뀌었습니다. 스크래치와 건반의 크기·위치는 그대로이고, 위젯이 차지하는 영역도 넓어지지 않았습니다.
- **KPS 스피드미터** : 계기판의 KPS가 속도계 게이지로 보이고, 빨간 영역에 들어가면 달아오릅니다. 설정에서 끄거나 프리셋(IIDX / BMS ~★★ / BMS ★★~)을 고를 수 있습니다.
- **위젯 꾸미기** : 스크래치 이미지 2장 모드(회전 방향마다 다른 이미지), 위젯 배경 투명, 건반 위 릴리즈 숫자 표시/숨기기, 롱노트 색
- **설정 즉시 반영 · 자동 재연결** : 설정을 저장하면 OBS 위젯에 바로 반영되고, 앱을 껐다 켜도 위젯이 알아서 다시 연결됩니다. 앱이 꺼져 있는 동안에는 OBS 화면에 "위젯 프로그램과 연결이 끊겼습니다"가 뜹니다.
- **세션 기록** (메뉴 → 세션 기록) : 이번 세션의 타건 수, 보낸 양, 남은 양을 보고 beatmania.app으로 바로 보낼 수 있습니다.
- **종료할 때 자동 전송** : 설정에서 켜면 앱을 끌 때 남은 타건 기록을 자동으로 보냅니다. 기본값은 꺼짐입니다.
- **가이드** (상단 메뉴 → 가이드) : 사용법, 연결 방법, 릴리즈, 채터링 가이드를 앱 안에서 볼 수 있습니다.

## 🔑 beatmania.app 계정 연결이 바뀌었습니다

- 토큰을 넣고 **연결**을 누르면 서버에 확인한 뒤 저장하고, **연결된 계정 이름**을 보여줍니다.
- 토큰은 이 PC의 Windows 계정으로 **암호화**해서 저장합니다.
- 2.x에서 넣어 두신 토큰은 자동으로 옮겨졌습니다. 설정에서 계정 이름이 보이면 그대로 쓰시면 됩니다.
- "저장된 토큰을 서버가 받아 주지 않습니다"가 보이면 [beatmania.app](https://beatmania.app) 마이페이지에서 토큰을 다시 복사해 넣어 주세요.
- 3.0.0을 쓴 뒤 2.x로 되돌리면 토큰을 다시 넣어야 합니다.
