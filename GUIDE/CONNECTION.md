# 🔌 처음이라면: 연결 가이드

[English](CONNECTION.en.md)

IIDXwidget 화면을 OBS 방송에 띄우는 방법을 **처음부터** 설명합니다.
IP, 포트 같은 말을 몰라도 괜찮습니다. 필요한 만큼만 설명할게요.

---

## 1️⃣ 먼저, 나는 원컴? 투컴?

- **원컴 방송** : 게임과 OBS를 **한 컴퓨터**에서 같이 돌립니다. → [원컴 연결](#-원컴-연결)로
- **투컴 방송** : 게임하는 컴퓨터(**게임 PC**)와 OBS를 켜는 컴퓨터(**방송 PC**)가 **따로** 있습니다. → [투컴 연결](#-투컴-연결)로

IIDXwidget은 항상 **컨트롤러가 꽂힌 컴퓨터**(게임 PC)에서 실행합니다.

---

## 2️⃣ 알아야 할 말 세 가지

### IP 주소 = 컴퓨터의 집 주소
- 인터넷 공유기에 연결된 컴퓨터는 저마다 번호를 하나씩 받습니다. 이게 **IP 주소**입니다. 보통 `192.168.0.12`처럼 생겼습니다.
- 다른 컴퓨터에 있는 화면을 불러오려면 그 컴퓨터의 IP 주소를 알아야 합니다.
- **`127.0.0.1`** 은 특별한 주소로, "**지금 이 컴퓨터 자신**"을 뜻합니다. 원컴 방송에서 씁니다.

### 포트 = 컴퓨터 안의 창구 번호
- 한 컴퓨터 안에서도 프로그램마다 쓰는 창구가 다릅니다. 이 창구 번호가 **포트**입니다.
- IIDXwidget은 **8080** 창구로 위젯 화면을 보여줍니다. 그래서 주소 끝에 `:8080`이 붙습니다.
- 5678이라는 창구도 쓰지만, 위젯이 알아서 연결하므로 신경 쓰지 않아도 됩니다.

### 같은 공유기 = 같은 집
- 투컴 방송이라면 두 컴퓨터가 **같은 공유기**에 연결되어 있어야 서로 찾을 수 있습니다.
- 유선이든 와이파이든 상관없고, 같은 공유기에만 연결되어 있으면 됩니다.

## 🖥 원컴 연결

1. IIDXwidget을 실행합니다.
2. OBS에서 **소스 목록**의 **＋** → **브라우저**를 고릅니다.
3. 이름은 아무거나 정하고 **확인**을 누릅니다.
4. 설정 창에서 아래처럼 입력합니다.
   - **URL** : `http://127.0.0.1:8080/widget/`
   - **너비** : `800`, **높이** : `600` (DP라면 **너비** `1320`)
   - **로컬 파일**은 체크하지 않습니다.
5. **확인**을 누르면 끝입니다. 건반을 눌러서 OBS 화면에 반응이 오는지 확인하세요.

## 🖥🖥 투컴 연결

### ① 게임 PC의 IP 주소 알아내기
**게임 PC**에서 합니다.

1. 키보드에서 **Windows 키 + R**을 누릅니다.
2. `cmd`를 입력하고 **확인**을 누릅니다. 검은 창이 뜹니다.
3. `ipconfig`를 입력하고 **Enter**를 누릅니다.
4. **IPv4 주소**라고 적힌 줄의 숫자를 적어둡니다. (예: `192.168.0.12`)
   - 여러 개가 보이면 `192.168.` 또는 `10.`으로 시작하는 것을 고르세요.

### ② 방화벽 허용하기
**게임 PC**에서 합니다.

- IIDXwidget을 처음 실행할 때 **Windows 방화벽** 창이 뜨면 **허용**을 누릅니다.
- 창을 놓쳤거나 실수로 취소했다면:
  1. 시작 메뉴에서 **Windows 보안**을 엽니다.
  2. **방화벽 및 네트워크 보호** → **방화벽에서 앱 허용**을 누릅니다.
  3. **설정 변경**을 누르고, 목록에서 **IIDXwidget**을 찾아 **개인** 칸에 체크합니다.
- 네트워크 종류가 **공용**으로 되어 있으면 연결이 막힐 수 있습니다. **설정 → 네트워크 및 인터넷 → (연결 중인 네트워크) 속성**에서 **개인 네트워크**로 바꿔주세요.
- 게임 PC가 리눅스라면 [사용법 가이드 → 리눅스](USAGE.md#-리눅스-실험적-지원)를 보세요.

### ③ OBS에 주소 넣기
**방송 PC**에서 합니다.

1. OBS에서 **소스 목록**의 **＋** → **브라우저**를 고릅니다.
2. **URL**에 ①에서 적어둔 IP를 넣습니다.
   - `http://192.168.0.12:8080/widget/` ← 숫자 부분을 내 IP로 바꾸세요.
3. **너비** `800`, **높이** `600`으로 두고(DP라면 너비 `1320`) **확인**을 누릅니다.

### ④ 잘 되는지 확인
- 방송 PC의 인터넷 브라우저(크롬 등)에 같은 주소를 넣어 보세요. 위젯이 보이면 연결은 성공입니다.
- 보이지 않는다면 아래 [안 될 때](#-안-될-때)를 보세요.

## 🛡 설치할 때 경고가 뜨면

- **"Windows의 PC 보호" 창이 떠요**
  - 코드 서명이 없는 프로그램이라 뜨는 Windows 기본 경고입니다. **추가 정보 → 실행**을 누르면 설치됩니다.
- **스마트 앱 컨트롤이 설치를 막아요 (Windows 11)**
  - 스마트 앱 컨트롤은 코드 서명이 없고 쓰는 사람이 많지 않은 프로그램을 막는 Windows 11 기능입니다. 이때는 **실행** 버튼이 없어서 그대로는 설치할 수 없습니다.
  - 끄는 법: **Windows 보안 → 앱 및 브라우저 컨트롤 → 스마트 앱 컨트롤 설정 → 끄기**
  - 설치가 끝나면 같은 곳에서 다시 **켜기**를 권장합니다. 개발자 PC에서는 다시 켠 뒤에도 앱 실행과 자동 업데이트가 됐지만, 모든 환경에서 된다고 장담할 수는 없습니다. 다시 켠 뒤 앱이나 업데이트가 막히면 다시 끄고 [Issues](https://github.com/Coldlapse/IIDXwidget/issues)로 알려주세요. (예전 Windows 11은 한 번 끄면 Windows를 초기화해야 다시 켤 수 있었지만, 최신 업데이트에서는 바로 다시 켤 수 있습니다)
  - 코드 서명이 없는 이유: 코드 서명 인증서는 비용이 꽤 들어서, 개인이 무료로 만드는 이 프로그램에는 아직 적용하지 못했습니다. 개발자로서는 안전하다고 말씀드리는 것 말고는 달리 증명할 방법이 없습니다. 소스 코드가 모두 공개되어 있으니 위험한지는 직접 확인하고 판단해 주세요.
- **2.1.0 이하 버전을 Windows Defender가 바이러스로 막아요**
  - 설치 파일이 `Trojan:Win32/Vigorf.A`, 설치된 파일 중 하나가 `Trojan:Win32/KeyLogger!AMTB`로 진단되는 경우가 있습니다. **오탐입니다.**
  - 키보드 모드에서 키 입력을 읽기 위해 쓰던 외부 부품이 키로거처럼 보여서 생긴 문제로, 3.0.0부터는 이 부품을 쓰지 않습니다. **최신 버전을 설치해 주세요.**
- **키 입력은 어떻게 쓰이나요?**
  - 키보드 모드에서만 키 입력을 읽고, 설정에서 매핑한 키만 위젯 표시에 사용합니다.
  - 키 입력은 인터넷으로 전송되지 않습니다. 인터넷으로 나가는 것은 **세션 기록** 페이지에서 전송을 누르거나, 직접 켠 **종료할 때 자동 전송**이 동작할 때의 타건 수 하나뿐입니다. 소스 코드가 모두 공개되어 있어 직접 확인할 수 있습니다.
- 최신 버전인데도 막힌다면 [Issues](https://github.com/Coldlapse/IIDXwidget/issues)로 알려주세요.

## ❗ 안 될 때

- **화면이 아예 안 떠요**
  - 게임 PC에서 IIDXwidget이 켜져 있는지 확인하세요.
  - 주소를 한 글자씩 다시 확인하세요. `http://`, `:8080`, 마지막 `/widget/`까지 모두 필요합니다.
- **"위젯 프로그램과 연결이 끊겼습니다"가 떠요**
  - 주소는 맞게 들어갔지만 IIDXwidget이 꺼져 있거나 다시 켜지는 중입니다. 앱을 켜면 알아서 다시 연결됩니다.
- **투컴에서 어제는 됐는데 오늘은 안 돼요**
  - 공유기가 게임 PC의 IP를 바꿨을 수 있습니다. ①을 다시 해서 IP가 같은지 확인하고, 바뀌었다면 OBS 주소도 고쳐주세요.
  - 매번 바뀌는 게 귀찮다면 공유기 설정에서 게임 PC에 **고정 IP**(IP 예약)를 걸어두면 됩니다. 방법은 공유기 제조사마다 다르니 "공유기 이름 + 고정 IP"로 검색해 보세요.
- **투컴에서 브라우저로도 안 열려요**
  - 두 컴퓨터가 같은 공유기에 연결되어 있는지, ② 방화벽 허용을 했는지 확인하세요.
- **"포트를 이미 사용 중"이라고 떠요**
  - 다른 프로그램이 8080을 쓰고 있습니다. 메뉴 → **설정**에서 **서버 포트**를 다른 숫자(예: 8081)로 바꾸고, OBS 주소의 `8080`도 같은 숫자로 바꾸세요.
- **업데이트했더니 위젯 모양이 예전 그대로예요**
  - OBS 브라우저 소스 속성에서 **현재 페이지의 캐시를 새로고침**을 한 번 눌러주세요.
- **컨트롤러가 인식되지 않아요**
  - 메뉴 → **로그**에서 원인을 확인할 수 있습니다. (예: "장치를 찾을 수 없습니다")
  - 케이블을 뺐다 다시 꽂으면 2초쯤 안에 재시작 없이 다시 연결됩니다. 앱을 켠 뒤에 꽂은 컨트롤러도 알아서 잡습니다.
  - 설정의 컨트롤러 프로필이 맞는지 확인하고, 목록에 없는 컨트롤러라면 **기타 컨트롤러 (수동 매핑)** 프로필을 써보세요. ([지원 범위](USAGE.md#컨트롤러-지원-범위))
  - 리눅스라면 컨트롤러 권한 규칙(udev)을 설치했는지 확인해 주세요. ([리눅스 안내](USAGE.md#-리눅스-실험적-지원))

그래도 안 되면 메뉴 → **로그** 내용을 캡처해서 [Issues](https://github.com/Coldlapse/IIDXwidget/issues)에 올려주세요.
